Answer
1. Create the parent-child tables
CREATE TABLE projects ( id INTEGER PRIMARY KEY, project_name TEXT NOT NULL ); CREATE TABLE tasks ( id INTEGER PRIMARY KEY, task_name TEXT NOT NULL, project_id INTEGER NOT NULL, FOREIGN KEY (project_id) REFERENCES projects(id) );
tasks is the child table: every project_id must already exist as an id in projects.
2. Insert all rows from both tables
INSERT INTO projects (id, project_name) VALUES (1, 'Mobile App'); INSERT INTO projects (id, project_name) VALUES (2, 'Website Redesign'); INSERT INTO projects (id, project_name) VALUES (3, 'Data Migration'); INSERT INTO tasks (id, task_name, project_id) VALUES (1, 'Design Login Screen', 1); INSERT INTO tasks (id, task_name, project_id) VALUES (2, 'Build Landing Page', 2); INSERT INTO tasks (id, task_name, project_id) VALUES (3, 'Clean Old Records', 3); INSERT INTO tasks (id, task_name, project_id) VALUES (4, 'Optimize Homepage Images', 2); INSERT INTO tasks (id, task_name, project_id) VALUES (5, 'Validate Data Checksums', 3);
3. Find all tasks in project_id = 2
SELECT * FROM tasks WHERE project_id = 2;

4. Challenge 🧩 - tasks for project_name = 'Website Redesign', using a JOIN
SELECT t.id, t.task_name, t.project_id FROM tasks t JOIN projects p ON t.project_id = p.id WHERE p.project_name = 'Website Redesign';
