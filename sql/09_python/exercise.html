db.py — copy as is
db.py
import sqlite3

DB_PATH = "movies.db"

def connect():
    conn = sqlite3.connect(DB_PATH)
    conn.row_factory = sqlite3.Row
    return conn

def run_query_select(sql, params=()):
    conn = connect()
    try:
        cursor = conn.cursor()
        cursor.execute(sql, params)
        rows = cursor.fetchall()
        return [dict(row) for row in rows]
    finally:
        conn.close()

def run_update_query(sql, params=()):
    conn = connect()
    try:
        cursor = conn.cursor()
        cursor.execute(sql, params)
        conn.commit()
        return cursor.lastrowid
    finally:
        conn.close()
This is the same db.py from Lesson 9. The only change is DB_PATH = "movies.db".

03

Write the DAL — movies_dal.py

DAL means Data Access Layer: the one file that talks to the database. Each function runs one query using a helper from db.py. main.py calls these functions and never writes SQL itself.

FunctionWhat it doesSQLdb.py helper
get_all_movies() Returns every movie SELECT run_query_select
get_movies_by_year(year) Returns all the movies from that year SELECT … WHERE run_query_select
update_movie_title(movie_id, new_title) Changes the title of that movie UPDATE … WHERE run_update_query
delete_movie(movie_id) Deletes that movie DELETE … WHERE run_update_query
insert_movie(title, director, year, genre, rating) Adds a new movie INSERT run_update_query
  • Every value that comes from the user goes in with a ? placeholder, like in Lesson 9: VALUES (?, ?) + ("Bob", 82).
  • One value still needs a tuple, so add the comma: (movie_id,).
  • You don't need to pass id when you insert. AUTOINCREMENT gives the new movie the next number.
04

Write the menu — main.py

Print the menu, read the user's choice, call the right DAL function, then print the menu again. Keep going until the user picks 6.

#OptionAsk the user forThen
1 Show all movies — Print every movie
2 Find movies by year a year Print all the movies from that year
3 Update movie title movie id, new title Change the title and print Movie updated!
4 Delete movie movie id Delete it and print Movie deleted!
5 Add new movie title, director, year, genre, rating Insert it and print Movie added!
6 Exit — Print Bye! and stop the loop
  • The menu runs in a loop and only stops on option 6.
  • input() always gives you text. Turn the year and the id into numbers with int(), and the rating with float().
  • Any other choice prints Invalid option and shows the menu again.
  • You can use a function for each option to keep main.py tidy. Keep it simple.

The movies table has 20 rows after setup_db.py runs once
movies_dal.py has the 5 functions, and main.py has no SQL in it
Every user value goes into the query with a ? placeholder
After each option the menu shows again
Option 6 ends the program
