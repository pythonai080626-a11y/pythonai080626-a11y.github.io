הטבלאות והנתונים

  • customersהלקוחות של החברה — מספר, שם ועיר
  • ordersכל שורה היא הזמנה אחת: איזה לקוח הזמין, וכמה שילם (total)

הריצו את שתי הפקודות למטה ב־DB Browser for SQLite (לשונית Execute SQL) — קודם יצירת הטבלאות ואחר כך הכנסת הנתונים — ואז כתבו את השאילתה שלכם.

1. יצירת הטבלאות
CREATE TABLE customers (
  id    INTEGER PRIMARY KEY,
  name  TEXT NOT NULL,
  city  TEXT
);

CREATE TABLE orders (
  id          INTEGER PRIMARY KEY,
  customer_id INTEGER NOT NULL,
  total       REAL NOT NULL,
  FOREIGN KEY (customer_id) REFERENCES customers(id)
);

שלבי הפתרון

נסו קודם לבד, ואם נתקעתם — לכו שלב אחרי שלב. יש יותר מדרך אחת נכונה; העיקר שהתוצאה נכונה.

  1. הבינו מה מבקשים

    קראו שוב את השאלה: צריך שם לקוח, מספר הזמנות וסכום כולל — ורק עבור שלושת הלקוחות הראשונים.

  2. איפה הכסף?

    הסכומים נמצאים בטבלת orders, בעמודה total. כל שורה היא הזמנה אחת, ולכן צריך לחבר את הסכומים של כל לקוח בנפרד: SUM(total), ולספור את ההזמנות שלו: COUNT(*).

  3. קבצו לפי לקוח

    כדי לחשב סכום לכל לקוח בנפרד משתמשים ב־GROUP BY customer_id. טיפ: התחילו רק מטבלת orders (בלי JOIN) ובדקו שהמספרים הגיוניים.

  4. הביאו את השם

    שם הלקוח נמצא בטבלה אחרת — customers. חברו אותה בעזרת JOIN על customers.id = orders.customer_id.

  5. רק שלושת הראשונים

    מיינו לפי הסכום הכולל מהגדול לקטן (ORDER BY … DESC; תנו לסכום שם בעזרת AS כדי שיהיה קל להתייחס אליו) והגבילו ל־3 שורות עם LIMIT 3.

💡 לזכור

סדר הכתיבה של השאילתה: SELECT → FROM → JOIN → GROUP BY → ORDER BY → LIMIT
