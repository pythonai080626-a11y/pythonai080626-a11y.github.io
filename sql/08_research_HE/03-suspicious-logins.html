🚨 כניסות חשודות

צוות האבטחה קיבל התראה: חשבון של אחד העובדים נכנס למערכת מישראל בבוקר, ובערב של אותו יום הופיעה כניסה נוספת לאותו חשבון — מרוסיה. אי אפשר להיות בשתי מדינות באותו יום, ולכן כנראה אחת הכניסות היא של תוקף.

אילו עובדים התחברו מיותר ממדינה אחת באותו יום?

כמה כניסות ביום מאותה מדינה — זה תקין. אנחנו מחפשים רק עובד שנכנס מיותר ממדינה אחת באותו תאריך. כניסה ממדינה אחרת ביום אחר לא נחשבת חשודה.

מה צריך להציג?

  • שם העובד
  • התאריך
  • כמה מדינות שונות נרשמו באותו יום

הטבלאות והנתונים

  • employeesהעובדים — מספר ושם
  • login_logsכל שורה היא כניסה אחת למערכת: מי נכנס, מתי (login_time — תאריך ושעה) ומאיזו מדינה

הריצו את שתי הפקודות למטה ב־DB Browser for SQLite (לשונית Execute SQL) — קודם יצירת הטבלאות ואחר כך הכנסת הנתונים — ואז כתבו את השאילתה שלכם.

1. יצירת הטבלאות
CREATE TABLE employees (
  id    INTEGER PRIMARY KEY,
  name  TEXT NOT NULL
);

CREATE TABLE login_logs (
  id          INTEGER PRIMARY KEY,
  employee_id INTEGER NOT NULL,
  login_time  TEXT NOT NULL,
  country     TEXT NOT NULL,
  FOREIGN KEY (employee_id) REFERENCES employees(id)
);
2. הכנסת הנתונים
INSERT INTO employees VALUES
  (1, 'Yael Cohen'),
  (2, 'James Walker'),
  (3, 'Lena Fischer'),
  (4, 'Omar Haddad');

INSERT INTO login_logs VALUES
  (1, 1, '2024-03-15 09:14:02', 'Israel'),
  (2, 1, '2024-03-15 21:33:45', 'Russia'),
  (3, 2, '2024-03-15 10:05:00', 'UK'),

שלבי הפתרון

נסו קודם לבד, ואם נתקעתם — לכו שלב אחרי שלב. יש יותר מדרך אחת נכונה; העיקר שהתוצאה נכונה.

  1. הבינו מה מחפשים

    אותו עובד + אותו יום + יותר ממדינה אחת. העמודה login_time שומרת תאריך וגם שעה (למשל 2024-03-15 09:14:02), אבל כדי להשוות בין ימים צריך רק את התאריך.

  2. חלצו את התאריך

    הפונקציה strftime('%Y-%m-%d', login_time) מחזירה את התאריך בלבד, למשל 2024-03-15.

  3. קבצו לפי עובד ולפי יום

    GROUP BY employee_id, strftime('%Y-%m-%d', login_time) — כך מתקבלת קבוצה אחת לכל עובד בכל יום.

  4. ספרו מדינות שונות

    בתוך כל קבוצה ספרו כמה מדינות שונות יש: COUNT(DISTINCT country). ה־DISTINCT חשוב — שלוש כניסות מאותה מדינה הן עדיין מדינה אחת. אחר כך השאירו רק קבוצות עם יותר ממדינה אחת: HAVING COUNT(DISTINCT country) > 1.

  5. הוסיפו את שם העובד

    השם נמצא בטבלת employees. חברו אותה בעזרת JOIN על employees.id = login_logs.employee_id.

💡 לזכור

אם תקבצו רק לפי עובד (בלי היום) תקבלו גם עובדים שנכנסו ממדינות שונות בימים שונים — וזה לא חשוד.
