משיק, מיתר מקביל ויחס שטחים במעגל

פתרון מלא ומנומק לשלושת סעיפי השאלה — מדמיון משולשים דרך משפט המשיק-מיתר, ועד ביטוי שטח המשולש CKD באמצעות S.

סעיף א׳ · דמיון משולשים סעיף ב׳ · יחס שטחים סעיף ג׳ · שטח △CKD

הנתון בציור

הציור להמחשה בלבד ואינו בהכרח מדויק ביחסים המספריים.
C, D, F על המעגל; CB משיק; BFA מקביל ל-CD.

נתון

  • C, D, F על מעגל
  • מ-F העבירו ישר מקביל ל-CD
  • CB משיק למעגל, חותך את המקביל ב-B
  • A על המשך BF
  • DF ∩ AC = K

מעבר מהיר בין הסעיפים

  • א △DCF ~ △CFB
  • ב S△CKF ⁄ S△CDF
  • ג S△CKD

משפטים שישמשו אותנו

  1. זווית בין משיק למיתר שווה לזווית ההיקפית הנשענת על אותה קשת, מהצד השני.
  2. זוויות מתחלפות בין ישרים מקבילים שוות.
  3. משפט דמיון זווית-זווית (ז.ז).
  4. משולשים בעלי אותו גובה: יחס השטחים שווה ליחס הבסיסים.
  5. משולשים דומים: יחס השטחים שווה לריבוע יחס הדמיון.
קו המחשבה: בסעיף א׳ נוכיח דמיון בין משולש DCF לבין משולש CFB, בעזרת זווית משיק-מיתר וזוויות מתחלפות. בסעיף ב׳ נשתמש בנקודה K שעל DF כדי להשוות שטחי משולשים בעלי אותו גובה. בסעיף ג׳ נחבר את שני הסעיפים הקודמים עם נתון נוסף על BC ⁄ FK, ונגיע לשטח המבוקש דרך יחס הדמיון בריבוע.
א

דמיון המשולשים

להוכיח: △DCF ~ △CFB

רעיון: זווית משיק-מיתר נותנת זוג זוויות שוות, וזוויות מתחלפות בין המקבילים CD, FB נותנות זוג זוויות שוות נוסף — ושני זוגות מספיקים לדמיון.
#טענהנימוק
1CD ∥ FBנתון
2∠DCF = ∠CFBזוויות מתחלפות בין המקבילים CD ∥ FB והחותך CF
3CB משיק למעגל בנקודה Cנתון
4∠BCF = ∠FDCזווית בין המשיק CB למיתר CF שווה לזווית ההיקפית ∠FDC הנשענת על קשת CF מהצד השני
5△DCF ~ △CFBמשפט דמיון זווית-זווית (ז.ז), לפי שורות 2 ו-4
∎ מש״ל
ב

יחס שטחים על אותו גובה

למצוא: S△CKF ⁄ S△CDF

נתון לסעיף זה: K נמצאת על הקטע DF, וכן KD ⁄ KF = 5 ⁄ 3.
רעיון: משולשים CKF ו-CDF חולקים קודקוד C ובסיסים על אותו ישר DF — כלומר אותו גובה, ולכן יחס השטחים שווה ליחס הבסיסים.
#טענהנימוק
1KD ⁄ KF = 5 ⁄ 3 ⟹ נסמן KF = 3t, KD = 5tנתון
2DF = DK + KF = 8tK נמצאת בין D ל-F על הקטע DF
3למשולשים CKF, CDF קודקוד משותף C ובסיסים KF, DF על אותו ישרמתוך היות K נקודה על הקטע DF
4לשני המשולשים אותו גובה מ-C אל הישר DFמסקנה משורה 3
5S△CKF ⁄ S△CDF = KF ⁄ DF = 3t ⁄ 8t = 3 ⁄ 8משולשים בעלי אותו גובה: יחס השטחים שווה ליחס הבסיסים
תשובה S△CKF ⁄ S△CDF = 3 ⁄ 8
∎ מש״ל
ג

שטח המשולש CKD באמצעות S

להביע: S△CKD

נתון לסעיף זה: BC ⁄ FK = 16 ⁄ 9, ו-S הוא שטח המשולש BCF.
רעיון: משני יחסי הדמיון (BC ⁄ FK) נמצא את יחס הדמיון k בין △DCF ל-△CFB, נעבור ליחס השטחים דרך k², ומשם נחלק את S△CDF לפי יחס הבסיסים DK ⁄ DF כמו בסעיף ב׳.
#טענהנימוק
1FK = KF = 3t (מסעיף ב) ⟹ BC = (16⁄9)·3t = 16t⁄3נתון: BC ⁄ FK = 16 ⁄ 9
2FD ⁄ BC = CF ⁄ FB = DC ⁄ CF = kיחס הדמיון בין הצלעות המתאימות ב-△DCF ~ △CFB (סעיף א׳): D↔C, C↔F, F↔B
3FD = DF = 8tהוכח בסעיף ב׳
4k = FD ⁄ BC = 8t ⁄ (16t⁄3) = 3 ⁄ 2הצבה משורות 1 ו-3
5S△DCF ⁄ S△CFB = k² = 9 ⁄ 4משולשים דומים: יחס השטחים שווה לריבוע יחס הדמיון
6S△DCF = (9⁄4)·S△CFB = (9⁄4)SS△CFB = S (נתון)
7S△CKD ⁄ S△CDF = DK ⁄ DF = 5t ⁄ 8t = 5 ⁄ 8אותו נימוק כמו בסעיף ב׳: קודקוד משותף C, בסיסים DK, DF על אותו ישר
8S△CKD = (5⁄8)·(9⁄4)S = 45⁄32 · Sהצבה משורות 6 ו-7
תשובה S△CKD = 45⁄32 · S
בדיקת סבירות: S△CKD + S△CKF = (45⁄32)S + (3⁄8)·(9⁄4)S = (45⁄32)S + (27⁄32)S = (72⁄32)S = (9⁄4)S = S△DCF ✓ — תואם בדיוק לשורה 6, כנדרש מכך ש-K מחלקת את △CDF לשני המשולשים CKD ו-CKF.
∎ מש״ל
