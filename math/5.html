📘 שני מעגלים משיקים מבפנים

משיק פנימי, יחס רדיוסים ומשיק משותף

פתרון מלא ומנומק לשלושת סעיפי השאלה - מציאת היחס R1/R2 מתוך שוויון זוויות, הוכחת BD = MD, ועד ביטוי O1C ו-AC באמצעות R2.

סעיף א׳ · יחס הרדיוסים סעיף ב׳ · BD = MD סעיף ג׳ · משיק משותף מ-A

הנתון בציור

הציור להמחשה בלבד ואינו בהכרח מדויק.
⊙O1 חיצוני (רדיוס R1), ⊙O2 פנימי (רדיוס R2), משיקים מבפנים ב-A.

נתון

  • ⊙O1, ⊙O2 משיקים מבפנים בנקודה A
  • O1A רדיוס המעגל החיצוני, O1A = R1
  • O2 נמצאת על הקטע O1A; רדיוס ⊙O2 הוא R2
  • O1A חותך את ⊙O2 בנקודה נוספת M
  • MD משיק ל-⊙O2 ב-M, חותך את הרדיוס O1B ב-D
  • ∠DO1M = ∠DO2M

מעבר מהיר בין הסעיפים

  • א יחס הרדיוסים R1/R2
  • ב AO1:BD והוכחת BD=MD
  • ג משיק משותף - O1C, AC

משפטים שישמשו אותנו

  1. משיק למעגל מאונך לרדיוס אליו - בנקודת ההשקה.
  2. במעגלים משיקים מבפנים, המרחק בין המרכזים שווה להפרש הרדיוסים (הגדול פחות הקטן).
  3. במשולש ישר-זווית: טנגנס זווית חדה = מול/ליד; קוסינוס = ליד/יתר.
  4. משפט פיתגורס במשולש ישר-זווית.
קו המחשבה: המשיק MD מאונך לקטע O1A בנקודה M (כי זהו גם רדיוס ⊙O2 וגם קטע מתוך O1A) - ולכן שני המשולשים O1MD ו-O2MD ישרי-זווית ב-M וחולקים את הצלע MD. השוואת הטנגנסים של הזוויות השוות הנתונות נותנת לנו ישירות O1M = O2M, ומכאן את היחס R1/R2 (סעיף א׳). בסעיף ב׳ נשתמש ביחס שבו D מחלקת את O1B כדי לחשב את MD ואת BD בנפרד ולהשוות. בסעיף ג׳ נבנה משולש ישר-זווית נוסף O1AC (המשיק המשותף מאונך ל-O1A ב-A) ונשתמש באותה זווית שחושבה בסעיף ב׳.
א

יחס הרדיוסים R1/R2

למצוא: R1/R2

רעיון: שני המשולשים O1MD ו-O2MD ישרי-זווית באותה נקודה M וחולקים את הצלע MD - שוויון הזוויות הנתון גורר ישירות שוויון הניצבים הנגדיים.
#טענהנימוק
1MD משיק ל-⊙O2 ב-M ⟹ O2M ⊥ MD; וכן O1, O2, M על ישר אחד (O1A) ⟹ O1M ⊥ MDמשיק מאונך לרדיוס בנקודת ההשקה
2במשולש O1MD (ישר-זווית ב-M): tan(∠DO1M) = MD/O1M. במשולש O2MD (ישר-זווית ב-M): tan(∠DO2M) = MD/O2Mיחס טנגנס בזווית חדה במשולש ישר-זווית
3נתון ∠DO1M = ∠DO2M ⟹ MD/O1M = MD/O2M ⟹ O1M = O2Mמשורה 2 וצמצום הקטע המשותף MD
4O2M = R2M נמצאת על ⊙O2
5O1M = O1O2 - O2M = (R1-R2) - R2 = R1-2R2מעגלים משיקים מבפנים: O1O2 = R1-R2; הנקודות O1, M, O2, A באותו סדר על הקטע
6משורות 3, 4, 5: R1-2R2 = R2 ⟹ R1 = 3R2חילוץ R1
תשובה: R1/R2 = 3
ב

היחס AO1:BD והוכחת BD=MD

נתון לסעיף זה: הנקודה D מחלקת את הרדיוס O1B ביחס O1D : DB = 5 : 4

1 מציאת היחס AO1 : BD
רעיון: O1B הוא רדיוס של ⊙O1 ושווה R1 - נחלק אותו ל-9 חלקים לפי היחס הנתון ונציב את R1=3R2 מסעיף א׳.
#טענהנימוק
1O1B = O1D + DB, וביחס O1D:DB=5:4 ⟹ O1D=5k, DB=4k ⟹ O1B=9kD נמצאת על הקטע O1B; נתון היחס
2O1B = R1 = 3R2 ⟹ 9k = 3R2 ⟹ k = R2/3O1B רדיוס ⊙O1; סעיף א׳
3O1D = 5R2/3, DB = 4R2/3הצבה
4AO1 : BD = R1 : DB = 3R2 : 4R2/3 = 9 : 4AO1=O1A=R1; הצבה וצמצום
תשובה: AO1 : BD = 9 : 4
2 הוכחת BD = MD
רעיון: משולש O1MD ישר-זווית ב-M (הוכח בסעיף א׳) - נחשב את MD דרך פיתגורס, ונשווה לתוצאה שקיבלנו עבור DB.
#טענהנימוק
1משולש O1MD ישר-זווית ב-M, עם O1M=R2 (סעיף א׳) ו-O1D=5R2/3 (סעיף ב׳.1)סעיף א׳ שורה 1; סעיף ב׳.1
2MD = √(O1D² - O1M²) = √((5R2/3)² - R2²) = √(16R2²/9) = 4R2/3משפט פיתגורס במשולש O1MD
3DB = 4R2/3מסעיף ב׳.1
4MD = 4R2/3 = DB ⟹ BD = MDמשורות 2, 3
∎ מש״ל
ג

משיק משותף מ-A

נתון לסעיף זה: מ-A מועבר המשיק המשותף לשני המעגלים, החותך את המשך O1B בנקודה C

1 ביטוי O1C באמצעות R2
רעיון: מכיוון שהמעגלים משיקים מבפנים ב-A, המשיק המשותף היחיד בנקודה זו מאונך ל-O1A - כך נוצר משולש ישר-זווית נוסף O1AC, עם אותה זווית שחושבה בסעיף ב׳.
#טענהנימוק
1המשיק המשותף ב-A מאונך ל-O1Aמשיק מאונך לרדיוס בנקודת ההשקה (לשני המעגלים כאחד, כי O1,O2,A על ישר אחד)
2משולש O1AC ישר-זווית ב-A; C על קרן O1B ⟹ ∠AO1C = ∠AO1B = ∠DO1Mשורה 1; C נמצאת על המשך O1B
3cos(∠DO1M) = O1M/O1D = R2/(5R2/3) = 3/5יחס קוסינוס במשולש O1MD הישר-זווית (סעיף ב׳)
4במשולש O1AC: cos(∠AO1C) = O1A/O1C ⟹ 3/5 = 3R2/O1C ⟹ O1C = 5R2יחס קוסינוס בזווית חדה; O1A=R1=3R2
תשובה: O1C = 5R2
2 ביטוי AC באמצעות R2
רעיון: באותו משולש ישר-זווית O1AC - פיתגורס.
#טענהנימוק
1משולש O1AC ישר-זווית ב-A, עם O1A=3R2 ו-O1C=5R2 (סעיף ג׳.1)סעיף ג׳.1
2AC = √(O1C² - O1A²) = √(25R2² - 9R2²) = √(16R2²) = 4R2משפט פיתגורס במשולש O1AC
תשובה: AC = 4R2  ·  (לב שימו: O1A=3R2, AC=4R2, O1C=5R2 - משולש פיתגורי 3-4-5, בדיקת היגיון נאה לתשובה.)

שרשרת ההוכחה בקיצור

∠DO1M = ∠DO2Mנתון; שני משולשים ישרי-זווית חולקים MD
←
O1M=O2M ⟹ R1=3R2סעיף א׳
←
O1D:DB=5:4 ⟹ MD=DB=4R2/3סעיף ב׳
←
משולש 3-4-5: O1A, AC, O1C = 3R2, 4R2, 5R2סעיף ג׳ - תשובה סופית
