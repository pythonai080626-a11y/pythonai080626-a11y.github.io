Topic 12

f-string Tricks 🖨️

You already drop values into a sentence with f"…{price}…". Add a colon inside the braces and everything after it becomes a format spec — an instruction about how to print that value. Two decimal places, aligned columns, fill characters, thousands separators, percentages. A handful of specs cover almost everything you will ever need.

printf.py
money = 1234567.891 print(f"{money:,.2f}") # 1,234,567.89
1

The Shape

Nothing before the colon changes — it is still the variable or expression you want printed. The spec goes after:

{ moneywhat to print :the colon ,.2fhow to print it }

Without a spec it prints whatever Python thinks is reasonable — which for money is usually wrong:

price = 59.23948762 print(f"The price is {price} dollars") print(f"The price is {price:.2f} dollars")
The price is 59.23948762 dollars The price is 59.24 dollars
💡 The braces can hold a whole calculation, not just a name: f"{a} + {b} = {a+b}" and f"{price + (price * tax)}" both work.
2

:.2f — digits after the dot

.2f means "a float, with exactly 2 digits after the dot". Change the number for more or fewer:

pi = 3.14159265 print(f"{pi:.2f}") # 3.14 print(f"{pi:.4f}") # 3.1416 print(f"{pi:.0f}") # 3

There is an older, harder way to do this — worth seeing once so you appreciate the spec:

import math price = 59.23948762 print(math.trunc(price * 100) / 100) # chops -> 59.23 print(f"{price:.2f}") # rounds -> 59.24
59.23 59.24
⚠️ The two results differ! math.trunc chops the extra digits off, while :.2f rounds them. For money you almost always want rounding.
3

< > ^ — alignment and width

A number after the alignment symbol is the total width. Python pads with spaces to reach it:

text = "Python" print(f"|{text:<10}|") # left print(f"|{text:>10}|") # right print(f"|{text:^10}|") # center
|Python | | Python| | Python |
💡 The symbol shows you which way the text is pushed: < points left, > points right, ^ is a roof in the middle.
4

Alignment builds a table

This is the whole trick behind printed tables. Fix every column at the same width and the | separators line up no matter how long the names are:

print(f"|{'name':^10}|{'age':^10}|") print("-" * 23) print(f"|{'danny':^10}|{'30':^10}|") print("-" * 23) print(f"|{'sharon':^10}|{'22':^10}|")
| name | age | ----------------------- | danny | 30 | ----------------------- | sharon | 22 |
💡 "-" * 23 repeats a character 23 times to draw the separator line — a string times a number is that string repeated.
⚠️ Watch your quotes. Writing f"…{"name"}…" — double quotes inside a double-quoted f-string — only works in Python 3.12+. On 3.10 and 3.11 it is a SyntaxError: f-string: expecting '}'. Use 'single' quotes inside a "double"-quoted f-string and it works everywhere.
5

, and _ — thousands separators

Long numbers are unreadable without separators. One character fixes it:

money = 1234567.89 print(f"{money:,}") # 1,234,567.89 print(f"{money:,.2f}") # 1,234,567.89 (also forces 2 decimals) print(f"{money:_}") # 1_234_567.89
1,234,567.89 1,234,567.89 1_234_567.89
💡 Specs combine, and the order is fixed: separator first, precision last. :,.2f is right; :.2f, is an error.
6

:05d — padding with zeros

d means "whole number". A 0 before the width says "pad with zeros instead of spaces":

number = 42 print(f"{number:05d}") # 00042 print(f"{number:5d}") # " 42" - spaces instead print(f"{7:02d}:{5:02d}") # 07:05 - a clock
00042 42 07:05
💡 Useful anywhere a value must always be the same length — invoice numbers, IDs, clock digits, file names that need to sort correctly.
7

:.1% and :+ — percent and sign

% multiplies by 100 and appends the sign for you:

percentage = 0.756 print(f"{percentage:.1%}") # 75.6% print(f"{percentage:.0%}") # 76%

+ forces a sign to show even on positive numbers:

print(f"{42:+}") # +42 print(f"{-42}") # -42 (minus always shows anyway)
75.6% 76% +42 -42
⚠️ Feed :% the fraction, not the percentage — 0.756, not 75.6. Getting this backwards gives you 7560.0%.
8

A width on its own — and who goes where

You can give a width with no alignment symbol. But "no symbol" does not mean "left":

x = 5 print(f"|{x:5}|") # a number → pushed RIGHT text = "Python" print(f"|{text:10}|") # text → pushed LEFT
| 5| |Python |
⚠️ Python's default depends on the type: numbers go right, text goes left. In a table with a mix of both, always write the <, > or ^ yourself — otherwise your columns fight each other.
9

A fill character — pad with something else

Put any single character before the alignment symbol and Python pads with it instead of spaces:

x = 5 print(f"{x:*<5}") # 5**** print(f"{x:*>5}") # ****5 print(f"{x:*^5}") # **5** print(f"{'menu':.<20}12.90") # a dotted menu line
5**** ****5 **5** menu................12.90
{ xwhat to print :the colon *fill ^align 5width }
💡 The order is fixed: fill, align, width. And this explains :05d — it is nothing but the fill character 0 in front of a width.
10

:.5 on text — cut it short

Same dot, different meaning. On a number .5 is "5 digits after the point"; on text it is "at most 5 characters":

text = "HelloWorld" print(f"{text:.5}") # Hello print(f"{text[:5]}") # Hello - the same, using a slice
Hello Hello
💡 Combine it with a width to get a column that can never overflow: f"|{name:<10.10}|" — always exactly 10 wide, however long the name is.
11

:8.2f — width and precision together

Two instructions glued into one spec: 8 is the total width of the column, .2f is the number itself.

pi = 3.14159 print(f"{pi:8.2f}") # 8 wide, 2 decimals # a column of prices that lines up on the dot print(f"{7.5:8.2f}") print(f"{142.375:8.2f}") print(f"{1999.9:8.2f}")
3.14 7.50 142.38 1999.90
💡 This is the spec that makes a receipt look like a receipt. Numbers default to right-aligned, so every decimal point lands in the same column for free.
