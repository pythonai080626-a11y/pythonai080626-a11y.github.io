set

Sets

A bag that never holds the same value twice and finds anything instantly, because it hashes instead of searching. No order, no [0] — but you get the two circles from school: |, &, -, ^, plus .add(), .discard() and frozenset.

dict

Dictionaries

Stop counting indexes — look things up by name. Every key points at a value, found instantly. .get() saves you from KeyError, .items() loops both halves at once, and .setdefault() fills in what is missing.

def

Functions

Write it once, call it forever. def gives a block of code a name, parameters let you feed it different values, and return hands the answer back. Plus what global really does and why every function deserves a docstring.

Explore topic
return

Functions 2

Now the function talks back. Parameters are the slots values arrive in, x=0 gives a slot a default, and naming it at the call — add(y=10) — makes the order stop mattering. Then return hands the answer back and ends the function on the spot — and when there is no return, you still get None.

Explore topic
immutable

Tuples

A list you are not allowed to change. ('a', 'b', 'c') keeps its order and its indexes — slicing, in, len, count and index all still work — but t[0] = 'z' is a TypeError. That lock is what lets a tuple be a dictionary key, and it is why the comma, not the brackets, is what really makes one.

Explore topic
safety net

Try / Except

A crash is not the end of the program — it is a choice. Wrap the risky line in try, catch what goes wrong by name with except ValueError as e, and the file keeps running instead of dying on a red traceback. else runs only when nothing broke, finally runs no matter what, and raise lets you throw the error yourself.
