Functions, Part 2 — In and Out 🔁

Last lesson your function had a name and a body. Today it gets a door on each side. Values go in through parameters — with default values for the ones the caller can skip, and the option to name them at the call so the order stops mattering. An answer comes back out through return, which also ends the function on the spot. And when there is no return at all, something still comes back: None — the difference between d.pop(), which hands you what it removed, and a.sort(), which hands you nothing.

A Name Inside the Brackets 📥

Last lesson every function had empty (), so every call did exactly the same thing. Put a name inside those brackets and the function gains a slot — a variable that does not exist yet, and gets its value from whoever calls.

def say_hello(name): print('Hello,', name) say_hello("Danny") say_hello("Mor")
Hello, Danny Hello, Mor

One function, two different results. The word in the def line and the value at the call have two different names, and it is worth getting them straight now:

WordWhereWhat it is
parameterdef say_hello(name):the empty slot — a promise that a value will arrive
argumentsay_hello("Danny")the real value you hand over at the call
The argument fills the parameter. When the function ends, the slot is gone.
The slot must be filled. A parameter with no default is not optional. Call say_hello() with nothing and Python stops you:
TypeError: say_hello() missing 1 required positional argument: 'name'

Two Slots, Filled Left to Right ↔️

Separate parameters with a comma and you get two slots. Python fills them in order: the first argument goes into the first parameter, the second into the second. Nothing clever, and nothing checks that you meant it that way.

def rectangle_area(width, height): return width * height print(rectangle_area(5, 10)) print(rectangle_area(10, 10)) print(rectangle_area(7.5, 12))
50 100 90.0
The callwidth becomesheight becomes
rectangle_area(5, 10)510
rectangle_area(10, 5)105
For a rectangle the area comes out the same either way, so a swap goes unnoticed. Try the same mistake on divide(a, b) and the answer is simply wrong. This is exactly the problem the next-but-one topic solves.

Default Values — a Slot That Fills Itself 🎁

Put an = in the def line and the slot gets a fallback. The caller may still pass a value, but no longer has to.

def say_hello(name="incognito"): ''' say hello to user :param name: name of the user. default is "incognito" :return: None ''' print('Hello,', name) say_hello() # nothing passed say_hello(danny) say_hello(mor) say_hello("John")
Hello, incognito Hello, Danny Hello, Mor Hello, John

Every slot can have one. Here both do, so the function survives being called with two arguments, one, or none at all:

def add(x=0, y=0): return x + y print(add()) # 0 — both defaults print(add(5)) # 5 — x=5, y still 0 print(add(5, 10)) # 15
One rule to remember. Slots without a default have to come first.
def f(a, b=0): # fine def f(a=0, b): # SyntaxError: non-default argument follows default argument
It makes sense if you think about the call: Python fills slots left to right, so it cannot skip a to reach b.

Using = When You Call It 🏷️

The = now shows up in two places that look identical and mean completely different things. This is the one to slow down on.

WhereLooks likeMeans
in the def linedef print_square(x=0):“if nobody passes one, use 0”
at the callprint_square(x=5)“this 5 goes in the slot called x”
Nothing is being assigned to a variable named x at the call. You are pointing at a slot by name. There is no x outside the function afterwards.
def print_square(x=0): ''' printing square :param x: number :return: None ''' print(x ** 2) print_square() # 0 — the default print_square(x=0) # 0 — named print_square(5) # 25 — positional print_square(10) # 100

Naming the slot buys you the thing the previous topic was missing: the order stops mattering.

def rectangle_area(width, height): return width * height rectangle_area(5, 10) # positional → 50 rectangle_area(width=5, height=10) # by name → 50 rectangle_area(height=10, width=5) # backwards → 50, still right # mixing is allowed — positional first, named after rectangle_area(7.5, height=12) # → 90.0 # but never the other way round # rectangle_area(width=7.5, 12) ← SyntaxError
Use it the moment a call stops explaining itself. book(4, 2, 1) means nothing in six months. book(adults=4, kids=2, rooms=1) still does.

return — Handing the Answer Back 📤

So far our functions have printed. Printing shows a value to a human and then it is gone — you cannot add to it, store it or pass it on. return hands the value back to the program instead.

def add(x=0, y=0): ''' add two numbers :param x: 1st number :param y: 2nd number :return: sum of x+y ''' sum_xy = x + y return sum_xy result = add(x=5, y=10) print('add returned', result) print(add(5, 10))
add returned 15 15
LineWhat happens
result = add(x=5, y=10)the function runs, and the value it returns is stored in result
print(add(5, 10))the returned value goes straight into print — no variable needed
print(sum_xy)NameError. sum_xy lived inside the function and is gone
print or return? If a human is the only one who needs to see it — print. If any other line of your program needs the value — return. When in doubt, return: the caller can always print it afterwards.

return Also Walks Out the Door 🚪

return does two jobs at once: it hands the value back, and it ends the function immediately. Nothing written after it runs. That is why these two are exactly the same function:

# 1 — with else def max_number(a=0, b=0): if a > b: return a else: return b # 2 — same thing, no else needed def max_number(a=0, b=0): if a > b: return a return b print(max_number(10, 9)) # 10

In the second version, if a > b is true we have already left the building — so the last line can only be reached when it was false. The else adds nothing.

A function may hand back any type it likes, and it can have several return lines. Whichever one runs first, wins:

def get_even_odd(a=0): ''' get even or odd number :param a: a number :return: "even" or "odd" ''' if a % 2 == 0: return "even" return "odd" print(get_even_odd(0)) print(get_even_odd(2)) print(get_even_odd(7)) print(get_even_odd(11)) print(get_even_odd(-3))
even even odd odd odd

And with everything from last lesson, a function can hand back a whole dictionary:

def count_letters(text): ''' count letters :param text: text phrase :return: dict of count of letters ''' d = {} for c in text: if c not in d: d[c] = 1 else: d[c] += 1 return d print(count_letters('missiiiissippi'))
{'m': 1, 'i': 7, 's': 4, 'p': 2}
This is last lesson's counting pattern with a def around it and a return at the end. That is all a function is — a block you already wrote, given a name and a way to answer.

No return? You Still Get Something: None 🕳️

A function without a return line does not hand back “nothing”. It hands back None — a real value, of a real type, that you can store and print.

def greeting(): ''' printing hello :return: None ''' print('hello, danny') greeting() # it prints x = greeting() # it prints again... print(x) # ...and hands back nothing
hello, danny hello, danny None

Notice what happened on the last two lines: the function did its job, and gave back None. Both are true at once. A function that only prints is doing half the work — useful to a human, useless to the rest of your program.

And when there is nothing to write in the body yet, Python still needs the indented block to exist. That is what pass is for:

def hi(): ''' this is my documentation :return: ''' pass help(hi)
pass means “deliberately empty”. It is how you sketch a function you have not written yet without breaking the file.

Gives It Back, or Changes It? ⚠️

This is not a beginner’s curiosity — it is the difference between two kinds of method you have been using since lesson 13, and it is behind one of the most common bugs there is.

d = {1: 'a'} res = d.pop(1) # pop RETURNS what it removed print(res) # a a = [4, 3] out = a.sort() # sort changes the list IN PLACE print(out) # None ← nothing came back print(a) # [3, 4] ← but the list did change
CallReturnsChanges the original?
d.pop(1)the removed valueyes
a.sort()Noneyes, in place
sorted(a)a new sorted listno
a.append(5)Noneyes, in place
The classic bug.
a = a.sort() # a is now None. The list is gone.
You threw the list away and kept the None. Ask it of every function you write and every method you call: does this give something back, or does it change something in place? It is almost never both.

Now the Docstring Has Real Work 📝

Last lesson a docstring said what the function did. Now that functions have slots and answers, it has two more jobs: say what goes in, and say what comes out.

def rectangle_area(width, height): ''' calculate area of rectangle :param width: width of rectangle :param height: height of rectangle :return: area of rectangle ''' return width * height help(rectangle_area)
LineWrite
first linewhat the function does, in a few words
:param name:one line per slot — what it means, and its default if it has one
:return:what comes back. Write None if the function only prints
Writing :return: None is not a wasted line. It tells the next reader — you, next week — not to go looking for a value that was never there.

Homework — Four Functions ✍️

Four small functions. Every one takes parameters and hands back an answer with return. Nothing here needs anything you have not met — no tuples, no try, just def, a couple of slots and a return.

Three rules for all four:
  1. Every function gets a docstring with :param for each slot and :return: for the answer. No exceptions — this is the habit we are building.
  2. Return, do not print. The print happens outside, on what came back.
  3. Call each one at least twice with different values, and print what came back.
1 · circle_area(radius) 🟠

One parameter, no default. Return the area — 3.14 * radius ** 2. Do not print inside.

def circle_area(radius): # docstring here # return the area print(circle_area(1)) print(circle_area(2.5)) print(circle_area(radius=10))
3.14 19.625 314.0
2 · is_adult(age=0) 🎂

A default value this time. Return True if the age is 18 or more, otherwise False. Return the answer — do not print it, and do not return the strings "True" / "False".

print(is_adult()) # the default kicks in print(is_adult(17)) print(is_adult(18)) print(is_adult(age=40))
False False True True
3 · apply_discount(price, percent=10) 💸

One required slot and one with a default. Return the price after the discount.

print(apply_discount(200)) # 10% — the default print(apply_discount(200, 25)) print(apply_discount(200, percent=50)) print(apply_discount(price=80, percent=5))
180.0 150.0 100.0 76.0
Remember the order rule: price has no default, so it has to come first in the def line.
4 · count_vowels(text) 🔤

A loop inside a function. Go through the text, count how many letters are vowels, and return the number.

def count_vowels(text): # docstring vowels = 'aeiou' count = 0 # loop over text, count the vowels # return count print(count_vowels('incognito')) print(count_vowels('missiiiissippi')) print(count_vowels('xyz'))
4 7 0
c in vowels answers “is this letter a vowel?” with True or False — the same in you used on dictionaries last lesson.

ארבע פונקציות קטנות. כל אחת מקבלת פרמטרים ומחזירה תשובה עם return. אין כאן שום דבר שלא למדתם — בלי tuple, בלי try, רק def, כמה פרמטרים ו-return.

שלושה כללים לכל הארבע:
  1. לכל פונקציה חייב להיות docstring עם :param לכל פרמטר ו-:return: לתשובה. בלי יוצאי דופן — זה ההרגל שאנחנו בונים.
  2. להחזיר, לא להדפיס. ה-print קורה בחוץ, על מה שחזר.
  3. קראו לכל פונקציה לפחות פעמיים עם ערכים שונים, והדפיסו מה חזר.
1 · circle_area(radius) 🟠

פרמטר אחד, בלי ברירת מחדל. החזירו את השטח — 3.14 * radius ** 2. בלי print בפנים.

print(circle_area(1)) print(circle_area(2.5)) print(circle_area(radius=10))
3.14 19.625 314.0
2 · is_adult(age=0) 🎂

הפעם עם ברירת מחדל. החזירו True אם הגיל 18 ומעלה, אחרת False. להחזיר — לא להדפיס, ולא להחזיר את המחרוזות "True" / "False".

print(is_adult()) print(is_adult(17)) print(is_adult(18)) print(is_adult(age=40))

3 · apply_discount(price, percent=10) 💸

פרמטר אחד חובה ואחד עם ברירת מחדל. החזירו את המחיר אחרי ההנחה.

print(apply_discount(200)) print(apply_discount(200, 25)) print(apply_discount(200, percent=50)) print(apply_discount(price=80, percent=5))
180.0 150.0 100.0 76.0
זכרו את כלל הסדר: ל-price אין ברירת מחדל, ולכן הוא חייב להופיע ראשון בשורת ה-def.
4 · count_vowels(text) 🔤

לולאה בתוך פונקציה. עברו על הטקסט, ספרו כמה אותיות הן תנועות, והחזירו את המספר.

def count_vowels(text): # docstring vowels = 'aeiou' count = 0 # loop over text, count the vowels # return count print(count_vowels('incognito')) print(count_vowels('missiiiissippi')) print(count_vowels('xyz'))
4 7 0
