Topic 14

The str Type ✂️

A string is not just text you print. It carries a toolbox of methods you reach with a dot — .upper(), .strip(), .split(), .center() — and it is also a row of characters you can index and slice: text[0], text[1:4], text[::-1].

01_str.py
msg = "step on no pets" print(msg == msg[::-1]) # True
1

len() and the dot

len() is a plain function that goes around the value. Everything else on this page is a method — the value comes first, then a dot, then the name and empty parentheses:

name = 'Danny' print(type(name)) # <class 'str'> print(len(name)) # 5 print(f'{name} is {len(name)} characters') name = 'danny' print(name.upper()) # DANNY ← the normal way print(str.upper(name)) # DANNY ← the same thing, written the long way
<class 'str'> 5 Danny is 5 characters DANNY DANNY
💡 Don't forget the empty (). name.upper without them does not run anything — it just refers to the method.
2

A string never changes

This is the one rule that trips everyone up. A method does not edit your string — it builds a new one and hands it back:

name = 'danny' name.upper() # ← the result is thrown away print(name) # danny - nothing happened name = name.upper() # ← store it back, now it counts print(name) # DANNY
'danny' .upper() → 'DANNY' a brand new string
⚠️ If a line that calls a method neither prints nor assigns the result, that line did nothing at all.
3

Changing the case

print('danny'.upper()) # DANNY print('YOSI'.lower()) # yosi print("AasdasBcccC".swapcase()) # aASDASbCCCc print("hello, world!! Good morning".capitalize()) print("hello, world!! good morNing".title())
DANNY yosi aASDASbCCCc Hello, world!! good morning Hello, World!! Good Morning
MethodWhat it does
.upper()every letter capital
.lower()every letter small
.swapcase()flips each letter — twice returns the original
.capitalize()first letter of the sentence up, everything else down
.title()first letter of every word up, everything else down
⚠️ capitalize() did more than add a capital H — it also pushed the existing G of Good back down. Both it and title() force everything else to lowercase.
💡 The everyday use is comparing input: answer.lower() == 'yes' accepts Yes, YES and yEs in a single line.
4

replace, split, strip

sentence = "Hello, World!!" print(sentence.replace("World", "Universe")) # every occurrence sentence = "Hello, World!! good morning" print(sentence.split()) # no argument = split on spaces sentence = "Hello*python*class*vip" print(sentence.split('*')) # any separator you like sentence = " Hello, World!! " print(f"'{sentence.strip()}'") # trims the edges only
Hello, Universe!! ['Hello,', 'World!!', 'good', 'morning'] ['Hello', 'python', 'class', 'vip'] 'Hello, World!!'

Because every method returns a new string, you can chain them left to right:

user_input = " jOhN_dOe_2026 " print(user_input.strip().lower().replace("_", "-"))
john-doe-2026
' jOhN_dOe_2026 ' → strip → 'jOhN_dOe_2026' → lower → 'john_doe_2026' → replace → 'john-doe-2026'
💡 strip() only touches the start and end — spaces in the middle stay. Printing inside '{…}' quotes is the easiest way to actually see them.
5

Questions that answer True / False

These return a bool, so they drop straight into an if — or into a named boolean variable:

sentence = "Hello, World!! good morning" print(sentence.startswith("Hello")) # True print(sentence.endswith("morning")) # True print("abcd".isalpha()) # True - letters only print("python3".isalpha()) # False - one digit ruins it print("1234".isdigit()) # True print("12 34".isdigit()) # False - the space is not a digit print("hi".islower()) # True print("HELLO".isupper()) # True print(" ".isspace()) # True
is_greeting = sentence.startswith("Hello") if is_greeting: # never: if is_greeting == True print('hello to you too')
⚠️ The rule is every character must pass. There is no "mostly" — one digit makes isalpha() False, one space makes isdigit() False.
💡 isdigit() is the safe way to check input before int(). int('abc') crashes with ValueError; if answer.isdigit(): lets you ask first.
6

zfill and center — padding

print("42".zfill(5)) # 00042 print('123456789ABC') # a ruler to count the width print('Hello!'.center(11, '-')) # ---Hello!-- print('Hello!'.center(11, ' ')) # Hello!
00042 123456789ABC ---Hello!-- Hello!

The same two jobs exist as f-string specs — and those work on numbers too, without converting first:

String methodf-string specResult
"42".zfill(5)f"{42:05}"00042
'hi'.center(10)f"{'hi':^10}"    hi    
'hi'.center(10, '*')f"{'hi':*^10}"****hi****
💡 When the padding does not divide evenly, the extra character can land on either side — do not count on perfect symmetry. Full spec list on the f-string Tricks page.
7

Index — every character is numbered

Counting starts at 0. Negative numbers count backwards from the end:

P0-6
y1-5
t2-4
h3-3
o4-2
n5-1
text = "Python" print(text[0]) # P - the first character print(text[-1]) # n - the LAST character
⚠️ "Python" has len 6, so the valid indexes are 0…5. text[6] raises IndexError: string index out of range.
💡 [-1] saves you from writing text[len(text) - 1], and it keeps working when the text changes length.
8

Slicing — [start:stop:step]

Two numbers with a colon give you a piece. The start is included, the stop is not — exactly like range():

P0
y1
t2start
h3
o4
n5stop

"Python"[2:5] → 'tho'

text = "Hello python course" print(text[0:3]) # Hel - 0,1,2 (3 not included) print(text[:5]) # Hello - no start = from the beginning print(text[0:]) # the whole string - no stop = to the end print(text[1:8:2]) # every 2nd character between 1 and 8 print(text[::2]) # every 2nd character of the whole string print(text[::-1]) # step BACKWARDS = reversed!
Hel Hello Hello python course el y Hlopto ore esruoc nohtyp olleH

The classic use of [::-1] — is it a palindrome?

msg = "step on no pets" print(msg == msg[::-1]) # True
💡 Indexing is strict, slicing is forgiving. text[19] on a 19-character string is an IndexError, but text[0:500] quietly gives you everything there is.
9

Looping over the characters

Until now for always walked over range(...). It can walk over a string too, handing you one character per round:

mech = "Python Core Study Mechanics" # by index for i in range(0, len(mech)): if not mech[i].isspace(): print(mech[i]) # for-each - shorter and safer for c in mech: if not c.isspace(): print(c)
for i in range(len(s))for c in s
The variable holdsa number — the positionthe character itself
Getting the characters[i]c
Use when…you need to know where you areyou only care what is there
⚠️ Use range(0, len(mech)), never a hard-coded range(0, 27). Change one word in the sentence and the hard-coded version breaks with an IndexError.
