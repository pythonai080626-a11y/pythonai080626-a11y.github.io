Question 1 for + if/else easy

🍕 Pizza Party Splitter🍕 מחלק הפיצות

Tonight you are in charge of the pizza 🍕 — several orders arrive, every pizza has a different number of slices, and every group of friends is a different size. Nobody is allowed to get half a slice.

  1. Ask how many orders there are, and read that number.
  2. If there are 0 orders → print no pizza tonight 🥲 and the program is over.
  3. Otherwise repeat once per order (you know the count before you start, so this is a for). In every round:
    • read how many slices the pizza has, then how many friends share it;
    • print each friend gets X slices, where X is slices // friends;
    • the leftover is slices % friends. If it is 0 print perfect split! 🎉, otherwise print leftover for the dog 🐶: N;
    • add this pizza's slices to a running total (a variable that starts at 0 before the loop).
  4. After the loop print total slices: … and average per order: … — the total divided by the number of orders.

הערב אתם אחראים על הפיצה 🍕 — מגיעות כמה הזמנות, בכל פיצה מספר משולשים אחר, וכל חבורת חברים בגודל אחר. אף אחד לא יכול לקבל חצי משולש.

  1. שאלו כמה הזמנות יש, וקראו את המספר.
  2. אם יש 0 הזמנות ← הדפיסו no pizza tonight 🥲 והתוכנית נגמרה.
  3. אחרת חזרו על סיבוב אחד לכל הזמנה (אתם יודעים את הכמות עוד לפני ההתחלה, אז זו לולאת for). בכל סיבוב:
    • קראו כמה משולשים יש בפיצה, ואז כמה חברים מתחלקים בה;
    • הדפיסו each friend gets X slices, כאשר X הוא slices // friends;
    • השארית היא slices % friends. אם היא 0 הדפיסו perfect split! 🎉, אחרת הדפיסו leftover for the dog 🐶: N;
    • הוסיפו את המשולשים של הפיצה הזו לסכום מתגלגל (משתנה שמתחיל ב־0 לפני הלולאה).
  4. אחרי הלולאה הדפיסו total slices: … ו־average per order: … — הסכום חלקי מספר ההזמנות.

Question 2 while True + if/elif/else medium

🌡️ The Weather Station🌡️ תחנת מזג האוויר

Your weather station reads temperatures one after another. Nobody knows how many will arrive today — the measuring stops only when the user says so.

  1. Before anything else, start two trackers: hottest = None and coldest = None.
  2. Now repeat forever (while True). In every round:
    • ask temp? and read the answer as text;
    • if it is done → break out of the loop;
    • otherwise turn it into a float — it can have a decimal point and it can be negative;
    • print the verdict with if / elif / else: above 30 → 🔥 heatwave, 15 and up → 😎 nice, 0 and up → 🧥 chilly, below 0 → 🥶 freezing;
    • update the two trackers if this temperature is a new record.
  3. After the loop: if hottest is still None print no measurements 🤷.
  4. Otherwise print the hottest, the coldest, and the spread = hottest - coldest.

תחנת מזג האוויר שלכם קוראת טמפרטורות אחת אחרי השנייה. אף אחד לא יודע כמה יגיעו היום — המדידה נעצרת רק כשהמשתמש אומר.

  1. לפני הכול, התחילו שני עוקבים: hottest = None ו־coldest = None.
  2. עכשיו חזרו לנצח (while True). בכל סיבוב:
    • שאלו temp? וקראו את התשובה כטקסט;
    • אם זה done ← בצעו break ויציאה מהלולאה;
    • אחרת המירו ל־float — יכולה להיות נקודה עשרונית ויכול להיות מינוס;
    • הדפיסו פסק דין ב־if / elif / else: מעל 30 ← 🔥 heatwave, 15 ומעלה ← 😎 nice, 0 ומעלה ← 🧥 chilly, מתחת ל־0 ← 🥶 freezing;
    • עדכנו את שני העוקבים אם הטמפרטורה הזו היא שיא חדש.
  3. אחרי הלולאה: אם hottest עדיין None הדפיסו no measurements 🤷.
  4. אחרת הדפיסו את הגבוהה ביותר, את הנמוכה ביותר, ואת הפער = הגבוהה - הנמוכה.

Question 3 while + only if medium

🚀 Rocket Fuel Countdown🚀 ספירה לאחור ודלק

The countdown has started 🚀 — but the engines are already burning fuel, and the bigger the number on the clock, the heavier the burn. Will there be anything left in the tank when the clock reaches zero?

  1. Read the starting fuel (a decimal number).
  2. Read the number the countdown starts from (a whole number).
  3. Now count down with a while loop, as long as the count is bigger than 0. On every tick:
    • the engines burn count * 2.5 fuel — subtract it from the tank;
    • if the fuel went below zero: print 💥 out of fuel at T-minus X and break;
    • print T-minus X | fuel left: Y;
    • go one down.
  4. After the loop, if there is still fuel left, print 🚀 LIFT OFF! fuel left: Y.

הספירה לאחור התחילה 🚀 — אבל המנועים כבר שורפים דלק, וככל שהמספר על השעון גדול יותר כך השריפה כבדה יותר. יישאר משהו במיכל כשהשעון יגיע לאפס?

  1. קראו את כמות הדלק ההתחלתית (מספר עשרוני).
  2. קראו את המספר שממנו מתחילה הספירה לאחור (מספר שלם).
  3. עכשיו ספרו לאחור בלולאת while, כל עוד המונה גדול מ־0. בכל תקתוק:
    • המנועים שורפים count * 2.5 דלק — החסירו מהמיכל;
    • אם הדלק ירד מתחת לאפס: הדפיסו 💥 out of fuel at T-minus X ובצעו break;
    • הדפיסו T-minus X | fuel left: Y;
    • רדו באחד.
  4. אחרי הלולאה, אם עוד נשאר דלק, הדפיסו 🚀 LIFT OFF! fuel left: Y.

🍫 The Vending Machine🍫 מכונת החטיפים

One customer walks up to the machine. Your program serves them from the first coin to the last — and it needs two loops, each with a completely different job.

Loop 1 — pick a snack. Ask for a snack code again and again until the code is legal, and set the price with an if / elif / else:

  • 1 → 🍫 chocolate, price 7  ·  2 → 🥔 chips, price 5  ·  3 → 💧 water, price 3
  • anything else → print unknown code, try again 😴 and ask once more

Loop 2 — take the money. Keep asking insert money: while the money paid so far is still less than the price. The machine only accepts these five:

🪙 1🪙 5🪙 10💵 20💵 50
  • Anything else (a 3, a 7, a 100…) is not real money here → print the machine spits it out 🪙 and ask again. It does not count and it does not get added.
  • Every accepted piece is added to the total paid, and counted.
  • Remember the biggest piece the customer used.

When there is enough money in the machine:

  • the change is paid - price — print it as one number, e.g. change: 27;
  • but if the change is 0 print no change, exact! 🎯 instead;
  • then the snack, and the receipt: how many pieces of money went in, the biggest one, and the average (paid / pieces).
⭐ Bonus — hand back real money. Instead of one number, give the change back as actual bills and coins, always the biggest first: 50, 20, 10, 5, 2, 1. How many 20s fit in the change? change // 20. What is left after them? change % 20 — and that leftover is what you carry on to the next size.
So 27 comes back as 1 x 20, 1 x 5, 1 x 2, and 47 as 2 x 20, 1 x 5, 1 x 2.

לקוח אחד מגיע למכונה. התוכנית שלכם משרתת אותו מהמטבע הראשון ועד האחרון — והיא צריכה שתי לולאות, לכל אחת תפקיד שונה לגמרי.

לולאה 1 — בחירת חטיף. בקשו קוד חטיף שוב ושוב עד שהקוד חוקי, וקבעו את המחיר ב־if / elif / else:

  • 1 ← 🍫 שוקולד, מחיר 7  ·  2 ← 🥔 חטיף, מחיר 5  ·  3 ← 💧 מים, מחיר 3
  • כל דבר אחר ← הדפיסו unknown code, try again 😴 ושאלו שוב

לולאה 2 — גביית הכסף. המשיכו לבקש insert money: כל עוד הכסף ששולם עד כה קטן מהמחיר. המכונה מקבלת רק את החמישה האלה:

🪙 1🪙 5🪙 10💵 20💵 50
  • כל דבר אחר (3, 7, 100) וכו׳ הוא לא כסף אמיתי כאן ← הדפיסו the machine spits it out 🪙 ובקשו שוב. הוא לא נספר ולא מתווסף.
  • כל פריט שהתקבל מתווסף לסכום ששולם, ונספר.
  • זכרו מהו הפריט הגדול ביותר שהלקוח הכניס.

כשיש מספיק כסף במכונה:

  • העודף הוא paid - price — הדפיסו אותו כמספר אחד, למשל change: 27;
  • אבל אם העודף הוא 0 הדפיסו במקום no change, exact! 🎯;
  • ואז את החטיף, ואת הקבלה: כמה פריטי כסף נכנסו, מהו הגדול ביותר, ומהו הממוצע (paid / pieces).
⭐ בונוס — להחזיר כסף אמיתי. במקום מספר אחד, החזירו את העודף כשטרות ומטבעות אמיתיים, תמיד מהגדול לקטן: 50, 20, 10, 5, 2, 1. כמה 20 נכנסים בעודף? change // 20. מה נשאר אחריהם? change % 20 — והשארית הזו היא מה שממשיכים איתו לגודל הבא.
כך 27 חוזר כ־1 x 20, 1 x 5, 1 x 2, ו־47 כ־2 x 20, 1 x 5, 1 x 2.

Question 5 while + if/elif/else spicy

🎰 Digit Detective🎰 בלש הספרות

A number walks in and you have to take it apart digit by digit 🕵️ — without strings and without lists. Two operators do the whole job: num % 10 hands you the last digit, and num // 10 throws that digit away.

  1. Read one whole number.
  2. If it is negative: print (minus ignored 🙈) and flip the sign yourself with num = num * -1 — abs() is not allowed here.
  3. Start your trackers: digit sum at 0, the counter at 0, and biggest / smallest digit at None.
  4. If the number is 0 it still has one digit — say so yourself: sum 0, biggest 0, smallest 0, count 1.
  5. Otherwise peel it with a while loop, as long as the number is bigger than 0:
    • take the last digit with num % 10;
    • add it to the sum, add 1 to the counter, and update biggest and smallest;
    • drop that digit with num = num // 10.
  6. Print the digit sum, the biggest digit, the smallest digit, the digit count, and the average digit (sum / count).
  7. Finally judge the number with if / elif / else: if the digit sum divides by 3 → lucky ✨, else if it is even → even vibes 🙂, otherwise plain 😐.

מספר נכנס ואתם צריכים לפרק אותו ספרה־ספרה 🕵️ — בלי מחרוזות ובלי רשימות. שני אופרטורים עושים את כל העבודה: num % 10 נותן לכם את הספרה האחרונה, ו־num // 10 זורק אותה.

  1. קראו מספר שלם אחד.
  2. אם הוא שלילי: הדפיסו (minus ignored 🙈) והפכו את הסימן לבד עם num = num * -1 — abs() אסור כאן.
  3. התחילו את העוקבים: סכום הספרות ב־0, המונה ב־0, והספרה הגדולה / הקטנה ביותר ב־None.
  4. אם המספר הוא 0 עדיין יש לו ספרה אחת — אמרו את זה בעצמכם: סכום 0, גדולה 0, קטנה 0, ספירה 1.
  5. אחרת פרקו אותו בלולאת while, כל עוד המספר גדול מ־0:
    • קחו את הספרה האחרונה עם num % 10;
    • הוסיפו אותה לסכום, הוסיפו 1 למונה, ועדכנו את הגדולה והקטנה;

⚠️ Edge cases: 0 as the very first answer → print no runs recorded 🤷 and stop (no average, no longest); and the boundaries 3600 and 10800, which belong to the slower group. And remember: the 0 itself is never a measurement — it must not join the total or become the shortest time.
💡 Hint: read the first time before the loop, then while seconds != 0: and read the next one at the end of the body — or use while True with a break, whichever you find clearer. Bonus: f'{minutes:02d}' pads a number with a leading zero, turning 2m into 02m.
