Remove Duplicates, Keep The Order

for loop · in · building a list

כתבו פונקציה בשם remove_duplicates פרמטר אחד, בשם items - רשימה היא מחזירה רשימה חדשה בלי כפילויות, כשהסדר המקורי נשמר עברו על הרשימה, והוסיפו איבר לרשימה החדשה רק אם הוא לא כבר בה

python program
def remove_duplicates(items):
    seen = []
    for item in items:
        if item not in seen:
            seen.append(item)
    return seen


print(remove_duplicates([1, 2, 2, 3, 1, 4]))
expected output
[1, 2, 3, 4]

Word Frequency

for loop · dict

כתבו פונקציה בשם word_frequency פרמטר אחד, בשם words - רשימה של מילים היא מחזירה מילון: כל מילה היא מפתח, וכמה פעמים היא הופיעה ברשימה היא הערך אפשר גם עם dict רגיל, ואפשר גם עם defaultdict שניתן למעלה

python program
from collections import defaultdict
def word_frequency(words):
    counts = {}
    for w in words:
        counts[w] = counts.get(w, 0) + 1
    return counts


print(word_frequency(['a', 'b', 'a', 'c', 'b', 'a']))
expected output
{'a': 3, 'b': 2, 'c': 1}

Is The Password Valid

strings · loop · combined conditions

כתבו פונקציה בשם is_valid_password פרמטר אחד, בשם password היא מחזירה True רק אם הסיסמה באורך 8 תווים לפחות, וגם יש בה לפחות ספרה אחת - אחרת False לבדיקה שתו הוא ספרה יש למחרוזת פעולה מוכנה

python program
def is_valid_password(password):
    if len(password) < 8:
        return False
    for ch in password:
        if ch.isdigit():
            return True
    return False


print(is_valid_password('abc12345'))
print(is_valid_password('ab1'))
print(is_valid_password('abcdefgh'))
expected output
True
False
False

Who Passed

כתבו פונקציה בשם filter_by_score שני פרמטרים: records (רשימה של מילונים, לכל אחד יש 'name' ו-'score') ו-threshold היא מחזירה רשימה של השמות (name) בלבד, של כל הרשומות שבהן score גדול או שווה ל-threshold
