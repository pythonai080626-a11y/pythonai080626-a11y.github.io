Combine Two Lists

list · concatenation

Inside The Range

if · and

כתבו פונקציה בשם in_range שלושה פרמטרים: n, low ו-high היא מחזירה True אם n נמצא בין low ל-high (כולל את שניהם), אחרת False השתמשו בתנאי אחד עם and, לא שני if נפרדים

python program
def in_range(n, low, high):
    return n >= low and n <= high


print(in_range(5, 1, 10))
expected output
True
