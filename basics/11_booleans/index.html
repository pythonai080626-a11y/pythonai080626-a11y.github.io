Topic 11

Booleans & the Ternary ✅

A comparison like age > 18 is not just something you put inside an if — it is a value, and values can be stored in variables. Give that variable a good name and your conditions start reading like English sentences. Then the ternary squeezes a whole four-line if/else onto one line.

booleans.py
age = 20 is_adult = age > 18 if is_adult: print('Have a Beer!')
1

bool — the fifth type

Everything you store has a type. Here is the roll-call, including the new one:

i = 5 # int - a whole number x = 5.5 # float - a number with a dot name = 'dana' # str - text nothing = None # NoneType - "nothing yet" is_open = True # bool - True / False

type() asks Python what something is:

print(type(name)) print(type(i == 6))
<class 'str'> <class 'bool'>
⚠️ Capital letters matter: True and False, never true / false. And they are not strings — 'True' in quotes is text, a completely different thing.
2

A comparison IS a value

This is the line that unlocks everything else. i == 6 is a question, and Python answers it with a value — which means you can store the answer:

i = 5 equal_6 = i == 6 # stores False equal_5 = i == 5 # stores True

💡 Every comparison operator produces a bool: ==, !=, <, >, <=, >= — and so does any combination joined with and, or, not.
3

Naming the condition

Once it is stored, the name is what appears in the if — and a good name explains itself:

age = 20 is_adult = age > 18 if is_adult: # reads like English print('Have a Beer!') else: print('Have a Coke!') if not is_adult: # the opposite print('Have a Coke!')
Write thisNot this
if is_adult:if is_adult == True:
if not is_adult:if is_adult == False:
⚠️ The variable is already True or False. Comparing it to True adds nothing but noise — every Python programmer will tell you the same.
4

Why bother — long conditions

Three sides make a legal triangle only when every two together are longer than the third. As a raw if that is a mouthful:

if a + b > c and b + c > a and c + a > b: # ...what is this asking? print('Legal Triangle')

Name it once, then use the name as many times as you like:

a = 3 b = 4 c = 8 is_legal = a + b > c and b + c > a and c + a > b if is_legal: print('Legal Triangle') else: print('Illegal Triangle') if is_legal: print('perimeter', a + b + c)
Illegal Triangle
5

Splitting one condition into pieces

To open a bank account you must be at least 21 and hold at least 5,000 in cash. In one line:

is_eligible = age >= 21 and cash >= 5000

Or as named pieces — longer, but each line says what it means:

is_old_enough = age >= 21 has_5000_cash = cash >= 5000 is_eligible = is_old_enough and has_5000_cash if is_eligible: print('Bank account opened!') else: if not is_old_enough: print(f'You need {21 - age} more years') if not has_5000_cash: print(f'You need {5000 - cash} more cash')
Enter your age: 19 Enter your cash: 3000 You need 2 more years You need 2000 more cash
💡 Here is the real payoff: because each piece has a name, the else can say exactly what is missing — and print both lines when both are missing. A single combined condition cannot do that.
6

The Ternary if

This four-line shape appears constantly — pick one of two values:

if is_even: print('even') else: print('odd')

Python says the same thing on one line:

print('even' if is_even else 'odd')
'even' if is_even else 'odd'
PartMeaning
'even'the value you get when the condition is True
if is_eventhe condition — the same thing you would put after a normal if
else 'odd'the value you get when the condition is False
💡 The order feels backwards — the answer comes before the question. Read it as an English sentence: "print 'even', if the number is even, otherwise 'odd'". That is exactly how it is written.
7

The ternary is a value

It does not have to sit inside print — it produces a value, so it can be stored, calculated with, or dropped straight into an f-string:

answer = 'even' if is_even else 'odd' print(f'The number is {"even" if is_even else "odd"}') final = price * 0.9 if is_member else price # 10% member discount
⚠️ Only for genuinely small choices. A ternary inside a ternary — 'a' if x else 'b' if y else 'c' — is legal Python and unreadable by humans. The moment you need a second condition, go back to if / elif / else.
